# Project Morpheus 2026

Official website for Project Morpheus 2026, a 24-hour hackathon hosted at STES Campus (SIT Lonavala & SKN). The site includes event details, problem statements, rules, and committees, with a cyberpunk Matrix-inspired visual identity.

## Highlights

- Single-page home experience with animated hero, sections, and CTA
- Dedicated pages for Problem Statements, Guidelines, Committees, and FAQs
- Optimized visuals for mobile and low-power devices
- Vite-powered build with modern React + Tailwind stack

## Tech Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn-ui
- Framer Motion animations
- Three.js for hero 3D model
- Vercel Analytics / Speed Insights

## Quick Start

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` - start the dev server
- `npm run build` - production build
- `npm run build:dev` - development build
- `npm run preview` - preview production build
- `npm run lint` - lint codebase

## Project Structure

```
src/
	components/     # Reusable UI and sections
	pages/          # Route-level pages
	lib/            # Helpers
	hooks/          # Custom hooks
```

## Deployment

Build output is in `dist/`. Deploy with any static host or Vercel.

```sh
npm run build
```
